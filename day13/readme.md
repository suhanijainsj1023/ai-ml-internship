# 📚 Student Score Prediction using Linear Regression

## 📌 Project Overview

This project predicts student scores based on the number of study hours using the Linear Regression algorithm from Scikit-learn. It demonstrates the basic Machine Learning workflow, including data loading, model training, prediction, and evaluation.

---

## 🎯 Objectives

- Understand the basics of Machine Learning.
- Build a Linear Regression model.
- Predict student scores based on study hours.
- Evaluate model performance using MAE, MSE, and R² Score.

---

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset

The dataset contains two columns:

- **Hours** – Number of study hours
- **Scores** – Student marks

Example:

| Hours | Scores |
|------:|-------:|
| 1.5 | 20 |
| 2.5 | 30 |
| 3.5 | 40 |

---

## 🤖 Machine Learning Model

- Linear Regression

---

## 📈 Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

---

## 🚀 Features

- Load dataset using Pandas
- Split dataset into training and testing sets
- Train a Linear Regression model
- Predict student scores
- Evaluate model performance
- Accept user input for study hours and predict score
